# Qué datos capturan la lógica del civil law
### Bitácora de diseño de una ontología del enunciado normativo

**Versión:** 1.0 · **Fecha:** 2026-09-07

Empecé este proyecto queriendo medir cuánto se parecen dos códigos civiles. Terminé construyendo otra cosa: ¿Qué datos, extraíbles de texto normativo no estructurado, capturan la lógica jurídica del civil law?
